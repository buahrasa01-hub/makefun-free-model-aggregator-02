A Node 22 aggregator for OpenAI Chat Completions and Anthropic Messages. It ranks free models from the trial brief, translates Anthropic requests to the gateway's Chat Completions API, and retries refusals on eligible alternatives. Run `node main.ts --list` to print the catalog. The operator runs `grade-local`.
